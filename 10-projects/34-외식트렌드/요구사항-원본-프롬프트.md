# CLAUDE CODE MASTER PROMPT
## Global Foodservice Trends Intelligence Dashboard

이 파일의 모든 요구사항을 기준으로 Visual Studio Code 환경에서 실행 가능한 대시보드 프로젝트를 생성하라.

---

# 1. 프로젝트 목적

전 세계 외식산업의 최신 뉴스, 신메뉴, 신규 브랜드, 소비자 트렌드, 외식기업 전략, 프랜차이즈, Restaurant Tech, M&A, 출점, 가격/원가/트래픽 관련 정보를 매일 자동으로 수집하고 분석하는 웹 대시보드를 구축한다.

주요 지역은 아래 3개 권역으로 구분한다.

1. ASIA
2. EUROPE
3. AMERICAS

추가로 GLOBAL 카테고리를 별도 운영한다.

최종 사용자는 외식기업 본사 기획/운영/교육/해외사업 담당자다.
단순 뉴스 클리핑이 아니라 다음 질문에 답할 수 있어야 한다.

- 지금 글로벌 외식업에서 무엇이 뜨고 있는가?
- 어느 지역에서 어떤 변화가 먼저 발생하고 있는가?
- 신규 메뉴와 식재료 트렌드는 무엇인가?
- 소비자 행동은 어떻게 변하고 있는가?
- 주요 외식기업들은 어디에 투자하고 있는가?
- 어떤 브랜드가 빠르게 확장하고 있는가?
- AI, 로봇, POS, 예약, 배달 등 Restaurant Tech는 어떻게 변하고 있는가?
- 한국 외식기업이 적용하거나 벤치마킹할 만한 사례는 무엇인가?

# 3. 데이터 수집 원칙

수집 데이터는 최근 기사 중심으로 가져온다.

기본 수집 범위:
- 최근 24시간

보조 범위:
- 최근 7일
- 최근 30일

기사마다 아래 데이터를 저장한다.

```ts
interface NewsArticle {
  id: string
  title: string
  titleKo: string
  source: string
  sourceUrl: string
  articleUrl: string
  publishedAt: string
  collectedAt: string
  region: 'GLOBAL' | 'ASIA' | 'EUROPE' | 'AMERICAS'
  country?: string
  category: TrendCategory
  brands: string[]
  keywords: string[]
  originalSummary: string
  koreanSummary: string
  whyItMatters: string
  koreaImplication: string
  trendScore: number
  businessImpactScore: number
  noveltyScore: number
  reliabilityScore: number
  totalScore: number
  sentiment: 'POSITIVE' | 'NEUTRAL' | 'NEGATIVE'
  isDuplicate: boolean
  duplicateGroupId?: string
  imageUrl?: string
}
```

# 6. 뉴스 중요도 Scoring

뉴스마다 100점 만점의 Trend Score를 계산한다.

기본 공식:

```txt
Total Score =
Business Impact 30%
+ Novelty 25%
+ Market Scale 20%
+ Source Reliability 15%
+ Korea Relevance 10%
```

점수 기준:

90~100 = MUST KNOW
80~89 = HIGH
70~79 = WATCH
60~69 = REFERENCE
59 이하 = LOW

대시보드에서 중요 뉴스는 색상 배지 대신 명확한 Label로 표현한다.

# 7. 중복 기사 처리

같은 사건이 여러 매체에서 보도된 경우 자동 중복 제거한다.

판정 기준:

- 제목 의미 유사도
- 동일 브랜드
- 동일 사건
- 동일 날짜 또는 ±2일
- 기사 본문 키워드 유사도

같은 사건은 대표 기사 1개만 메인 화면에 노출한다.

단, 아래 조건이면 별도 기사로 유지한다.

- 서로 다른 지역의 영향 분석
- 새로운 수치 또는 데이터 추가
- 다른 기업의 대응 사례
- 후속 기사
